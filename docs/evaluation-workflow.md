# TenderHub Evaluation Workflow

## 1. Overview

TenderHub manages bid evaluation through a structured process that separates:

- Bid submission
- Compliance review
- Evaluator scoring
- Evaluation completion
- Evaluation approval
- Award decision

The core evaluation workflow is:

```text
Submitted Bid
      ↓
Bid Review
      ↓
Compliance Review
      ↓
Eligible Bid
      ↓
Evaluation
      ↓
Criterion Scoring
      ↓
Weighted Score Calculation
      ↓
Evaluation Completion
      ↓
Evaluation Approval
      ↓
Award Decision
