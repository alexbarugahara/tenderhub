# TenderHub Contract Workflow

## 1. Overview

TenderHub manages contracts created from procurement awards.

The core contract workflow is:

```text
Solicitation
      ↓
Bid
      ↓
Evaluation
      ↓
Award
      ↓
Contract
      ↓
Contract Documents
      ↓
Milestones
      ↓
Payments
      ↓
Completion / Expiry / Termination
