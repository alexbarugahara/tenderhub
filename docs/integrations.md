# TenderHub Integrations

## 1. Overview

TenderHub supports integrations with external systems that extend procurement, financial, payment, identity, and government-related capabilities.

The integration workflow is:

```text
Organization
      ↓
Integration
      ↓
External Provider
      ↓
Configuration
      ↓
Connection
      ↓
Synchronization
      ↓
Integration Sync Logs
      ↓
Monitoring / Error Handling
