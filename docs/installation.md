# TenderHub Installation Guide

## 1. Overview

This document describes how to install and run TenderHub locally for development.

TenderHub is built with:

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Auth.js
- Tailwind CSS

The application uses the Prisma schema in `prisma/schema.prisma` as the source of truth for the database structure.

---

## 2. Prerequisites

Install the following software before setting up TenderHub:

- Node.js
- npm
- Git
- PostgreSQL

Verify the installations:

```bash
node --version
npm --version
git --version
